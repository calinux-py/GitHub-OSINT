# GitHub OSINT Web Extension

GitScope is a browser extension for performing OSINT research on public GitHub profiles and repositories.

It helps surface useful public information such as account details, repositories, commit metadata, contributors, activity, and other publicly available GitHub signals in one place.

## Features

* Analyze public GitHub profiles
* Review repository information and activity
* Extract public commit author and committer metadata
* View contributors, branches, releases, languages, and other repository details
* Collect public references related to unavailable or restricted repositories
* Export investigation data as JSON
* Optional GitHub API token support for higher rate limits
* Runs locally in your browser

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions` or `edge://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Select the GitScope extension folder.

Then open a GitHub profile or repository and launch GitScope.
